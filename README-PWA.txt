STUG Guarda — PWA

Ficheiros:
- index.html: aplicação
- manifest.webmanifest: configuração PWA
- sw.js: cache/offline do app shell
- icon-192.png / icon-512.png: ícones Android/PWA
- apple-touch-icon.png: ícone iOS

Publicação:
1. Coloque estes ficheiros juntos num servidor HTTPS.
2. Abra a aplicação no navegador.
3. No Android/Chrome use "Instalar app".
4. No iPhone/iPad use Partilhar -> Adicionar ao ecrã principal.

Nota: o mapa Leaflet/OpenStreetMap e outros recursos externos continuam a depender de internet
quando não estiverem previamente disponíveis em cache.
